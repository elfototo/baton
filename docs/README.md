# Screenshots

Drop images here and uncomment the block at the top of the root `README.md`.

What is worth capturing, in order of usefulness:

1. **`preview.png`** — the plugin open on a real frame: live preview on the left,
   code on the right. This is the one image people actually look at.
2. **`consts.png`** — the `consts.tsx` tab, showing repeated blocks folded into an
   array. It makes the main claim of the project visible at a glance.
3. **`theme.png`** — the Tailwind theme tab, showing named colour tokens.
4. **`before-after.png`** — optional, but the strongest: the Figma frame beside
   the rendered preview.

Practical notes:

- Shoot at 2× (Retina) and keep the width around 1600 px.
- Use a design that is not under NDA.
- PNG for interface, and keep each file under ~500 KB so the page stays quick.
